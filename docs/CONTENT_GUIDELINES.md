# Content Guidelines

Write for developers.

Not search engines.

Content should feel like official documentation.

Avoid AI filler.

Avoid repeating definitions.

Every explanation should answer:

- Why?
- When?
- How?
- What if?
- Common mistakes?

Prefer:

Examples

Tables

Code snippets

Flow diagrams

Decision trees

Comparison charts

Avoid walls of text.

Every section should provide unique value.

Never duplicate explanations across tools.

Always explain concepts from first principles.

Every example should be realistic.

Use real variable names.

Use production-style code.

Never use lorem ipsum style examples.
