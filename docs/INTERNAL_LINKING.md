# Internal Linking Strategy

Every page should link to:

Related tools

Related landing pages

Relevant guides

Official references

Navigation should form topical clusters.

Example

JWT Decoder

↓

JWT Encoder

Base64 Decoder

Base64 Encoder

Hash Generator

JSON Formatter

Avoid orphan pages.

Every page should be reachable within three clicks.

Use descriptive anchor text.

Avoid generic links like:

Click here

Read more

Instead use:

JWT Encoder

Base64 Decoder

RFC 7519

etc.
