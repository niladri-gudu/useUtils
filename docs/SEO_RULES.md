# SEO Rules

Every page should target:

One primary keyword

3-8 secondary keywords

10+ long-tail keywords

Google People Also Ask questions

Related searches

Search intent should drive content.

Never optimise only for definitions.

Answer:

How?

Why?

When?

Can?

Should?

Difference between?

Best practices?

Common mistakes?

Every page should satisfy the complete topic.

Topical completeness is more important than keyword density.
